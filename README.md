# A Greener Jordan — GitHub Pages website

This folder is ready for GitHub Pages. You do **not** need to install software or know how to code.

## Easiest way to publish

1. Go to GitHub and create an account if you do not already have one.
2. Click **New repository**.
3. Name it `agreenerjordan`.
4. Choose **Public**.
5. Create the repository.
6. On the new repository page, choose **Add file → Upload files**.
7. Upload **all files inside this folder**. Do not upload this folder itself as another folder.
8. Click **Commit changes**.
9. Open **Settings → Pages**.
10. Under **Build and deployment**, choose **Deploy from a branch**.
11. Choose branch **main** and folder **/(root)**, then click **Save**.
12. Wait a few minutes. GitHub will show the website address on the Pages screen.

Your address will normally look like:

`https://YOUR-GITHUB-NAME.github.io/agreenerjordan/`

## Important

- Keep `index.html` in the main/root folder of the GitHub repository.
- Keep the other `.html` files, `style.css`, `script.js`, `.nojekyll` and the PDF beside it.
- The map opens Google Maps in a new browser tab and the embedded map needs an internet connection.
- The website does not require a server, database or paid hosting.
- Community creation is a local demo until a real shared database/login system is added. This means visitors on different phones will not yet see the same communities.
- Replace any project contact details before publishing if you want visitors to contact the project directly.

## Device support

The layout is responsive for phones, tablets, laptops/desktops and large TV screens. It uses standard HTML, CSS and JavaScript and does not require an app installation.
